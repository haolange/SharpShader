# SharpShader

SharpShader is the independent shader compiler, reflection, logical resource
identity, and source generation stack used by Infinity Engine and other .NET
applications. The core package does not depend on SharpGPU; GPU integration is
provided by `SharpShader.SharpGPU`.

Build, test, package, native asset provenance, and platform handoff gates are
documented in [docs/VERIFICATION.md](docs/VERIFICATION.md).
